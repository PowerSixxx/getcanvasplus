How it works

  1. Add Canvas+ to Chrome

    Free, nothing to set up.

  2. Open a course’s Modules page

    You’ll see a “Download all files (.zip)” button. It’s also on the course’s Files page.

  3. Save the .zip

    Canvas+ packs everything right in your browser and saves one .zip, one folder per module.

What you get

Organised like the course

One folder per module, so the .zip looks like the course does.

Modules and Files

Picks up files linked in Modules and the ones on the Files page.

Packed in your browser

Files go straight from Canvas to your computer — nothing is uploaded anywhere. The zip code is open source on GitHub.

Tells you what it skipped

Locked files, videos and outside links can’t be packed — Canvas+ lists them so nothing goes missing silently.

Questions

Can I download all Canvas files at once?

Not with Canvas alone: files linked in Modules open one by one, and many courses hide the Files page. Canvas+ adds a button that downloads the whole course as one .zip.

Is it free?

Yes, downloading course files is free.

Can I download files from a course I’m not in?

No. Canvas+ uses your own Canvas login, so it can only download what you can already open.
