Canvas GPA 计算器

Canvas GPA 计算器：GPA 直接从 Canvas 算出来。

Canvas+ 读取你在 Canvas 里的最终成绩和当前成绩，算出累计 GPA 和本学期结束后的预估——不用做表格，也不用一门门手动输入。

免费添加到 Chrome

免费 · 支持 Chrome 和 Edge · 任何用 Canvas 的学校都能用

怎么用

  1. 把 Canvas+ 添加到 Chrome

    免费，直接在 Canvas 页面上运行。

  2. 打开「期末计算器」

    点 Canvas 右侧边缘的 Canvas+ 小标签（或按 ⌘K / Ctrl+K），累计 GPA 就在最上面。

  3. 核对学分，试试“如果”

    打开「课程与学分」确认每门课的学分，再给课程选不同等级，看本学期会怎样影响 GPA。

有什么用

累计 + 本学期

根据已结束学期估算累计 GPA，再预估本学期结束后的结果。计算代码在 GitHub 开源。

期末前算“如果”

每门课先按当前成绩对应的等级计算，选一个不同的等级就能看到影响。

按你学校的标准

等级来自每门课在 Canvas 里的评分标准，也可以用你自己设的标准。

P/F 课程也处理好了

S / U 课程计入学分，但不计入 GPA。

常见问题

这是我的官方 GPA 吗？

不是，这是根据 Canvas 里的成绩做的估算。官方 GPA 以成绩单为准。

任何学校都能用吗？

只要学校用 Canvas 就能用。学校的等级标准不一样的话，可以自己设置。

免费吗？

免费，GPA 计算器属于免费版功能。

在你自己的 Canvas 上试试。

免费。用 Google 或邮箱验证码登录，不用密码。你的成绩不会离开你的浏览器。
