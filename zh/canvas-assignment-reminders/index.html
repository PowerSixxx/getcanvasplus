Canvas 作业提醒

真的会提醒你的 Canvas 作业提醒。

所有课程的作业、测验和讨论按截止时间排在一个列表里，每项到期前都会弹出通知——就算没打开 Canvas 也会提醒。

免费添加到 Chrome

免费 · 支持 Chrome 和 Edge · 任何用 Canvas 的学校都能用

怎么用

  1. 把 Canvas+ 添加到 Chrome

    免费。登录一次，截止时间就自动出现，不用设置。

  2. 打开「作业」

    点 Canvas 右侧边缘的 Canvas+ 小标签（或按 ⌘K / Ctrl+K），所有要交的都在一个列表里。

  3. 点一下铃铛

    允许通知，再选提醒时间：提前 24 小时和/或 2 小时。

有什么用

所有课程一个列表

按截止时间排序，实时倒计时，标出每项占总成绩多少。

不只是截止时间

出分、老师改了截止时间或发了公告，都会弹出通知。

考试也会提醒

从 syllabus 里读出考试日期，提前 3 天和 1 天提醒。

日历和待办

把截止时间导出到 Google / Apple 日历，勾选完成会和 Canvas 待办同步。日历导出代码开源。

常见问题

Canvas 会发作业提醒吗？

Canvas 的通知设置大多只告诉你变化，而且要一门门设置。Canvas+ 会在每个截止时间前弹出桌面提醒，所有课程集中在一处。

需要一直开着 Canvas 吗？

不用。只要 Chrome 开着，提醒就会以 Chrome 通知的形式弹出。

免费吗？

免费。作业列表、提醒、出分通知和日历导出永久免费。

在你自己的 Canvas 上试试。

免费。用 Google 或邮箱验证码登录，不用密码。你的成绩不会离开你的浏览器。
