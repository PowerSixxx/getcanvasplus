怎么用

  1. 把 Canvas+ 添加到 Chrome

    免费，不用任何设置。

  2. 打开课程的「单元」页面

    会看到「下载所有文件 (.zip)」按钮，课程的「文件」页面上也有。

  3. 保存 .zip

    Canvas+ 直接在浏览器里打包，保存成一个 .zip，每个单元一个文件夹。

有什么用

和课程结构一样

每个单元一个文件夹，打开 .zip 就像打开这门课。

单元和文件都包括

「单元」里链接的文件和「文件」页面上的文件都会收进来。

在浏览器里打包

文件直接从 Canvas 下载到你的电脑，不会上传到任何地方。打包代码在 GitHub 开源。

跳过了什么会告诉你

锁定的文件、视频和外部链接没法打包，Canvas+ 会列出来，不会悄悄漏掉。

常见问题

能一次下载 Canvas 的所有文件吗？

只靠 Canvas 不行：「单元」里的文件只能一个个打开，很多课程还隐藏了「文件」页面。Canvas+ 加了一个按钮，把整门课下载成一个 .zip。

免费吗？

免费，下载课程文件是免费功能。

能下载我没选的课的文件吗？

不能。Canvas+ 用的是你自己的 Canvas 登录，只能下载你本来就能打开的内容。

在你自己的 Canvas 上试试。
